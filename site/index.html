Installation

Configure once, then install and manage through APT.

1. Configure the repository (first time only)

curl -fsSL https://zeyadzero.github.io/Zeyad-Monitor/setup.sh | sudo bash

2. Install Zeyad Monitor

sudo apt install zeyad-monitor

3. Update Zeyad Monitor

sudo apt update
sudo apt upgrade

Repository setup is required only once per machine. Future installations and updates use standard APT commands.
